# برنامج جرد المستودعات | Warehouse Inventory

تطبيق ويب يعمل على الجوال (PWA) لإدارة جرد المستودعات وتسجيل البضاعة المصروفة يومياً.

## المميزات

- 📦 **إدارة الأصناف**: إضافة أصناف برصيد افتتاحي ووحدة قياس وحد تنبيه
- 📤 **تسجيل المصروف اليومي**: تسجيل البضاعة المصروفة لكل موقع مع التاريخ والمستلم والملاحظات
- 📊 **متابعة الرصيد**: عرض الرصيد الحالي لكل صنف تلقائياً
- 🔔 **تنبيهات المخزون**: تنبيه عند نفاد أو انخفاض الرصيد
- 📍 **حسب المواقع**: فلترة وعرض المصروف حسب الموقع والتاريخ
- 💾 **يعمل بدون إنترنت**: البيانات محفوظة محلياً على الجهاز
- 📲 **قابل للتثبيت**: يمكن تثبيته كتطبيق على الجوال
- 📁 **نسخ احتياطي**: تصدير/استيراد البيانات بصيغة JSON، وتصدير CSV

## التشغيل

افتح `index.html` في المتصفح، أو شغّل سيرفر محلي:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000` على جوالك أو متصفحك.

## التثبيت على الجوال

1. افتح الموقع في Chrome / Safari
2. اختر "إضافة إلى الشاشة الرئيسية"
3. سيظهر التطبيق كأيقونة مستقلة
