# غرف الشيوخ — غرفتين نوم + دورة مياه

نموذج ثلاثي الأبعاد ومخططات تنفيذية معمارية للتصميم: **7.60 × 6.00 م**، المساحة الإجمالية **45.60 م²**، الارتفاع الصافي 2.70 م.

## الملفات

| الملف | المحتوى |
|---|---|
| `غرف الشيوخ.mp4` | فيديو: جولة ثلاثية الأبعاد ثم لوحات المخططات التنفيذية |
| `غرف الشيوخ - المخططات التنفيذية.pdf` | 7 لوحات للمقاول: المسقط بالمقاسات، الأثاث، الواجهات، القطاعات، الجداول، الإضاءة، الملاحظات |
| `index.html` + `scene.js` | العارض ثلاثي الأبعاد في المتصفح (جولة، تجوّل حر، إخفاء السقف) |
| `drawings.html` + `drawings.js` | اللوحات التنفيذية (تُفتح في المتصفح وتُطبع) |
| `render.js` | تصدير فيديو الجولة إطاراً بإطار عبر Chromium + ffmpeg |
| `export-drawings.js` | تصدير اللوحات إلى PNG و PDF |

## المقاسات المعتمدة

| العنصر | المقاس |
|---|---|
| الغلاف الخارجي | 7.60 × 6.00 م، جدران خارجية 0.20 م، داخلية 0.10 م |
| غرفة نوم 1 و 2 | 2.80 × 5.60 م صافي (15.68 م² لكل غرفة) |
| دورة المياه | 1.40 × 3.00 م (4.20 م²) |
| ممر الدخول | 1.40 × 2.50 م (3.50 م²) |
| صافي الغرف | 39.06 م² |
| منسوب الأرضية | +0.30 م عن الحديقة |
| الارتفاع | صافي 2.70 م، سماكة السقف 0.30 م، أعلى السقف +3.30 م من الحديقة |
| D1 باب المدخل | 1.00 × 2.40 م خشب شرائح |
| D2 باب غرفة النوم (×2) | 0.90 × 2.40 م |
| D3 باب دورة المياه | 0.80 × 2.40 م |
| W1 واجهة زجاجية سحاب (×2) | 2.40 × 2.40 م ألمنيوم أسود |
| W2 شباك دورة المياه | 0.60 × 0.60 م، جلسة 1.90 م |
| W3 شباك خلفي لغرفة النوم (×2) | 1.60 × 1.40 م، جلسة 0.90 م |
| السرير | 1.80 × 2.00 م |

## الفروقات عن اللوحة الأصلية

- طول المبنى 7.60 م بدل 7.00 م حتى يبقى عرض غرفة النوم 2.80 م (مقاسات اللوحة الأصلية لا يتطابق مجموعها مع 7.00 م).
- السرير 1.80 × 2.00 م بدل 1.60 × 2.00 م.
- عمق غرفة النوم 5.60 م كما في رسم المسقط (المكتوب في اللوحة 4.20 م).
- المخططات معمارية فقط: الإنشائي والكهرباء والسباكة تحتاج مكتباً هندسياً.

## التشغيل

```bash
npm install                      # three@0.170.0
python3 -m http.server 8000      # ثم افتح http://localhost:8000/house3d/
node render.js --out tour.mp4    # فيديو الجولة
node export-drawings.js sheets   # اللوحات PNG + PDF
```
