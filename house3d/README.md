# تصميم ثلاثي الأبعاد — غرفتين نوم + دورة مياه

نموذج ثلاثي الأبعاد للمخطط (7.00 × 6.00 م، المساحة 42 م²، ارتفاع السقف 3.00 م) مع فيديو جولة.

- `house-3d-tour.mp4` — فيديو الجولة (52 ثانية، 1280×720).
- `index.html` — عارض تفاعلي في المتصفح: زر **الجولة** يشغّل نفس الجولة، وزر **تجوّل حر** للدوران بالماوس/اللمس، وزر **إخفاء السقف** لرؤية الغرف من الأعلى.
- `scene.js` — النموذج (الجدران، الفتحات، الأثاث، الإضاءة، الحديقة) ومسار الكاميرا.
- `render.js` — يصدّر الفيديو إطاراً بإطار عبر Chromium + ffmpeg.

## التوزيع المعتمد في النموذج

| العنصر | المقاس |
|---|---|
| الغلاف الخارجي | 7.00 × 6.00 م، جدران خارجية 20 سم، داخلية 10 سم |
| غرفة نوم 1 و 2 | 2.50 × 5.60 م صافي لكل غرفة |
| دورة المياه | 1.40 × 3.00 م |
| ممر الدخول | 1.40 × 2.50 م |
| باب المدخل D1 | 1.00 × 2.40 م خشب شرائح |
| واجهات زجاجية W1 | 2.10 × 2.40 م سحاب، ألمنيوم أسود |
| شباك دورة المياه W2 | 0.60 × 0.60 م علوي |

### المساحات (صافي داخلي)

| الفراغ | المقاس | المساحة |
|---|---|---|
| غرفة نوم 1 | 2.50 × 5.60 م | 14.00 م² |
| غرفة نوم 2 | 2.50 × 5.60 م | 14.00 م² |
| دورة المياه | 1.40 × 3.00 م | 4.20 م² |
| الممر | 1.40 × 2.50 م | 3.50 م² |
| المساحة الصافية للغرف | | 35.70 م² |
| المساحة الإجمالية للمبنى (مع الجدران) | 7.00 × 6.00 م | 42.00 م² |

ملاحظة: مقاسات اللوحة الأصلية (0.20 + 2.80 + 0.20 + 1.40 + 0.20 + 2.80 + 0.20) مجموعها 7.80 م وليس 7.00 م،
لذلك تم الالتزام بالأبعاد الخارجية 7.00 × 6.00 م وتعديل عرض الغرف إلى 2.50 م.

## التشغيل

```bash
npm install                 # three@0.170.0
python3 -m http.server 8000 # ثم افتح http://localhost:8000/house3d/
node render.js --out tour.mp4
```
