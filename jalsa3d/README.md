# الجلسة الخارجية — الوضع الشتوي

مجسّم ثلاثي الأبعاد وفيديو جولة لجلسة خارجية بمظلة ألمنيوم وزجاج سحاب.

| الملف | المحتوى |
|---|---|
| `الجلسة الخارجية - الوضع الشتوي.mp4` | فيديو الجولة (44 ثانية، 1280×720) مع موسيقى |
| `الجلسة الخارجية - المخططات التنفيذية.pdf` | 7 لوحات للمقاول: المسقط بالمقاسات، الأثاث، الواجهات، القطاعات، الجداول، الإضاءة والتمديدات، الملاحظات |
| `drawings.html` + `drawings.js` | اللوحات التنفيذية (تُفتح في المتصفح، وتُصدَّر بـ `node export-drawings.js sheets`) |
| `index.html` + `scene.js` | العارض ثلاثي الأبعاد في المتصفح (جولة، تجوّل حر، فتح السقف) |
| `parts/` | الأجزاء المصدرية: `a_`…`f_` تُجمع إلى `scene.js`، و`dr_head.js` + `dr_sheets.js` إلى `drawings.js` |
| `music.py` | يولّد الموسيقى المصاحبة (تأليف أصلي بالبرنامج، بدون عينات) |
| `render.js` | تصدير الفيديو إطاراً بإطار عبر Chromium + ffmpeg |

## المقاسات

| العنصر | المقاس |
|---|---|
| المظلة | 6.00 م عرض × 5.00 م عمق (30 م²)، ارتفاع 3.00 م فوق المصطبة |
| المصطبة | ارتفاع 0.60 م، 4 قوائم درج × 0.15 م، عرض الدرج 2.80 م |
| السقف | شرائح متحركة على فتحتين، 24 شريحة في كل فتحة |
| الواجهة الأمامية | 5 ألواح زجاج سحاب بعرض 1.14 م مفتوحة على الحديقة، اللوح الأيسر هو المدخل |
| الجانب الأيمن | 4 ألواح زجاج |
| الخلف واليسار | جدار خشب شرائح مع إضاءة جدارية |
| التلفزيون | مخفي في كبت 1.80 × 0.45 × 0.90 م خلف الزجاج الأمامي، يطلع بالريموت (شاشة 65 بوصة) |
| الكنب | شكل U بعمق 0.80 م: 5.70 م في الخلف وذراعان 2.00 م |
| طاولة النار | 1.90 × 0.66 م رخام أسود في وسط الجلسة |
| الدفاية | هرمية بارتفاع 2.15 م في الركن الأمامي الأيمن، تبعد 1.35 م عن أقرب مقعد |

## التشغيل

```bash
cat parts/[a-f]_*.js > scene.js                              # إعادة تجميع المشهد بعد أي تعديل
cat parts/dr_head.js parts/dr_sheets.js > drawings.js        # إعادة تجميع اللوحات
npm install                         # three@0.170.0
node render.js --out tour.mp4       # فيديو بدون صوت
python3 music.py music.wav 44       # الموسيقى
```

> ملاحظة: المخططات التنفيذية (PDF) ما زالت تُظهر جدار التلفزيون، وتحتاج تحديث للكبت المخفي.
