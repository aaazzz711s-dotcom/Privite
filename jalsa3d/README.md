# الجلسة الخارجية — الوضع الشتوي

مجسّم ثلاثي الأبعاد وفيديو جولة لجلسة خارجية بمظلة ألمنيوم وزجاج سحاب.

| الملف | المحتوى |
|---|---|
| `الجلسة الخارجية - الوضع الشتوي.mp4` | فيديو الجولة (42 ثانية، 1280×720) مع موسيقى |
| `index.html` + `scene.js` | العارض ثلاثي الأبعاد في المتصفح (جولة، تجوّل حر، فتح السقف) |
| `parts/` | أجزاء `scene.js` المصدرية (تُجمع بالترتيب الأبجدي) |
| `music.py` | يولّد الموسيقى المصاحبة (تأليف أصلي بالبرنامج، بدون عينات) |
| `render.js` | تصدير الفيديو إطاراً بإطار عبر Chromium + ffmpeg |

## المقاسات

| العنصر | المقاس |
|---|---|
| المظلة | 6.00 م عرض × 5.00 م عمق (30 م²)، ارتفاع 3.00 م فوق المصطبة |
| المصطبة | ارتفاع 0.60 م، 4 قوائم درج × 0.15 م، عرض الدرج 2.80 م |
| السقف | شرائح متحركة على فتحتين، 24 شريحة في كل فتحة |
| الواجهة الأمامية | 5 ألواح زجاج سحاب بعرض 1.14 م، اللوح الأيسر هو المدخل |
| الجانب الأيمن | 4 ألواح زجاج |
| الخلف واليسار | جدار خشب شرائح مع إضاءة جدارية |
| جدار التلفزيون | خشب شرائح 2.20 × 2.30 م في منتصف الواجهة من الداخل، مقابل الكنب، يبعد 0.55 م عن الزجاج |
| الكنب | شكل U بعمق 0.80 م: 5.70 م في الخلف وذراعان 2.00 م |
| طاولة النار | 1.90 × 0.66 م رخام أسود في وسط الجلسة |
| الدفاية | هرمية بارتفاع 2.15 م في الركن الأمامي الأيمن، تبعد 1.35 م عن أقرب مقعد |

## التشغيل

```bash
cat parts/*.js > scene.js           # إعادة تجميع المشهد بعد أي تعديل
npm install                         # three@0.170.0
node render.js --out tour.mp4       # فيديو بدون صوت
python3 music.py music.wav 42       # الموسيقى
```
